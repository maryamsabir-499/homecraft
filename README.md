# HomeCraft: Interior Design & Home Improvement Blog

A modern blog about interior design, room ideas, furniture guides and home organization.

   **Live site:** https://homecraft-psi.vercel.app

## Features

- Responsive design (mobile, tablet, desktop)
- Home, Blog, Categories, About, Contact, Privacy Policy and Terms pages
- Search and category filtering
- 5 original articles with internal linking
- SEO titles, meta descriptions, sitemap.xml and robots.txt
- Optimized WebP images

## Tech Stack

- React + Vite
- Tailwind CSS v4
- React Router
- React Helmet Async

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
